# exercise-check

Short pages that ask a few friends to describe their own exercises. This repo holds only the built pages; they are made elsewhere.

`describer/` is the Describer: a page that logs a gym session by describing each exercise instead of naming it. Open it with the link you were given; the first name you type is what your record is kept under.

`finder/` is its old address, from when it was called the Exercise Finder. It forwards to `describer/` and keeps the code after the #, so an old link still opens the same record.
